# Assignment 4 - Cryptanalysis of Shift Cipher

## Objective

The objective of this assignment is to implement and analyze the Shift Cipher and perform cryptanalysis using:

1. Brute Force
2. Dictionary Scoring
3. Chi-Square Analysis

The recovered keys from dictionary scoring and Chi-Square analysis are compared with the actual encryption key.
